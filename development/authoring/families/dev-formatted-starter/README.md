# dev-formatted-starter: runnable DEV starter

Generated by the scaffold CLI from the reviewed HCl dilution template. Canonical AB six-character IDs in an isolated DEV namespace, fixed level1, seeded level2 and inverse-volume level3. Provider and marking are pure; registry is DEV-only. No production registration or publication. Changing chemistry requires fresh source/chemistry checks.

Run from apps/Masters-of-Chemistry:

```powershell
node --test development/authoring/families/dev-formatted-starter/family.test.mjs
node node_modules/typescript/bin/tsc --project development/authoring/families/dev-formatted-starter/tsconfig.json
node development/authoring/serve.mjs --refinement
# Open http://127.0.0.1:5181/development/authoring/families/dev-formatted-starter/preview.html
# In another shell:
node development/authoring/families/dev-formatted-starter/browser.mjs
```

The preview mounts the actual unchanged ActivityHost with this registry. Fixtures verify fixed/72seeded configurations, correct/wrong/incomplete input, code+seed restore, first evidence/timing, correction/reload, canonical3level revision and teacher no-evidence. Outputs go to validation/component-fidelity/f1-correction/identity/authoring/dev-formatted-starter.

Edit data/provider/marking/scaffolds and regenerate provenance deliberately when authoring new chemistry. See docs/authoring/new-activity.md for genuinely new activity/gem metadata and optional editor integration.
