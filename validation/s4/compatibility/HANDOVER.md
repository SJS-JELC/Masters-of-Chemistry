## Source limitations and factual errata

Legacy curriculum result stores hold original IDs/scores/dates and optional flags/timing, not raw first answers or question-level marks. Import does not manufacture those fields. Old acid V1 and hidden Ka/pKa evidence remain historical; they do not become acid V2 mastery. Original scheduler/preferences/practice drafts are retained as exact raw source archives with precise unsupported reasons; they cannot create independent evidence or invent missing first responses/timing. They are not new-platform attempt snapshots. C3 original saved drawings/completion use the S3 substantive graph/answer adapter and remain separate Olympiad state, with no curriculum rows.

Same-origin old-key reads occur only when the user selects the read button; imports occur only after the separate reviewed-source import button. Cross-origin storage is unavailable to ordinary browser code; the UI explains paste/file exports and the 10 MB source bound. Invalid/unsupported/excluded source records remain present in exact raw archives and explicit report exclusions. Source archive save failure prevents importing that source and offers retry/export without claiming durability. First imported vs later duplicate receipts may produce two honest outcome reports; identical outcomes are deduplicated by their exact report fingerprint.

Raw archive fingerprints always identify exact source text. Curriculum batch receipt fingerprints combine the exact raw fingerprint and the canonical accepted-record projection fingerprint. This prevents unchanged source inputs from colliding merely because a previous import included another store: equal cross-store rows remain in each source batch and the repository deduplicates original attempt IDs. A genuinely conflicting projection is explicit in the exclusions/outcome, has its own receipt fingerprint and cannot overwrite immutable first evidence. Actual browser fixtures cover together → alone → together and conflicting-presence imports. No question-content versioning is added.

S0 evidence remains untouched. `source-audit.json` records two factual inventory wording corrections: the original IGCSE diagram page uses `DC`, while A Level uses `DAC`; original historical acid custom codes use `ABL`, not `ABC`. Tests follow actual original sources and retained fixtures. No invented aliases were added. Original teacher-only mixed diagram examples with empty grade lists remain available in review; curriculum selection excludes them.

The first prefix browser probe used the wrong C3 heading in its test selector and is retained separately. The source-confirmed heading fixed the probe; no source chemistry or original output changed. An initial storage-error UI test expected a summary that was overwritten by the repository's more precise namespace error; the corrected test checks the actual displayed failure and enabled retry/export.

No original stores, app files, dependencies, builds, Git metadata, teacher exports, chemistry, shared UI or root configuration were written. No deployment, backend, hydration or account work occurred. Requested worker model/effort: Sol 6.1 / High. Effective settings and usage are not exposed.
