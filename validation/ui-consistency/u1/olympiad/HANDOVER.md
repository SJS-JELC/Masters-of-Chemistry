## Exact completion definition

Dim (`unstarted`) means zero currently checked correct contributions. It also covers absent progress, wrong challenge identity, invalid drawing state, unchecked work and stale checks. This is a display state, not a claim that the pupil never opened the challenge.

For C3L6 the total is 31 contributions: ten classifications, twelve products and nine network structures. The existing policy recalculates chemical correctness and validated dependency completion. The selector additionally checks each relevant current fingerprint: classifications always; checked product-unit contributions only after validated part (a); checked network contributions only after validated part (b). One or more current checked correct contributions is partial. All three freshly validated completion flags must be true for full brightness. Old/stale checked counts are excluded even when the policy recomputes a current correct count.

For seven isomers the total is seven exact placements. The existing policy requires the saved drawing fingerprint and both aggregate counts to agree with current drawings. Only `fullyCorrect` contributes; `wrongPlace` alone does not light the gem. Current `fullyCorrect` from one to six is partial; validated completion with seven exact placements is full. Edits that invalidate the current check become dim until checked again.

The lit gem uses a vertical clip across the same genuine faceted geometry. Full completion lights the entire gem. Partial height follows correct/total, bounded from15% to85% to keep early and near-complete progress distinguishable. This visual minimum does not change the underlying counts or status.
